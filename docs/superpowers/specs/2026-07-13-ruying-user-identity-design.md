# 如影 Code 左下角身份区设计

## 目标

重新设计侧栏左下角的 GWM SSO 身份区，让姓名和工号具有清晰的信息层级，并在窄侧栏、长姓名和异步状态下保持稳定布局。

## 范围

本次只调整 `RuyingUser` 的视觉布局、退出入口和相关状态展示。不改变 SSO、身份数据结构、退出接口、侧栏宽度或其他导航组件。

## 视觉结构

登录后的身份区使用一行三列结构：

1. 左侧为 30×30 像素的文字头像，圆角 8 像素，采用低饱和品牌色背景。
2. 中间为可收缩的双行身份文本。第一行是姓名，使用 12px 中等字重；第二行是工号，使用 10–11px 等宽字体和弱化颜色。
3. 右侧为独立的 28×28 像素“更多操作”按钮，显示省略号图标。

身份区与侧栏内容之间保留分隔线，整体使用紧凑但明确的内边距。退出登录不再作为常驻文本占据第三行。

## 内容规则

- 姓名存在时，姓名作为第一行主信息，工号作为第二行辅助信息。
- 姓名缺失时，工号作为第一行主信息，第二行省略。
- 头像取主信息中第一个可见字符；没有可用字符时显示通用用户标识。
- 姓名和工号都保持单行，空间不足时使用省略号截断。
- 被截断或可能截断的文本通过 `title` 提供完整内容。
- 文本容器必须设置 `min-width: 0`，操作按钮不得被压缩，避免姓名、工号和按钮相互挤压。

## 交互

点击“更多操作”按钮打开轻量菜单。菜单只包含“退出登录”，保持本次范围精简。

- 按钮提供“用户操作”无障碍名称，支持键盘聚焦和激活。
- 退出过程中菜单项禁用并显示“正在退出…”。
- 退出成功后沿用现有逻辑：先清除身份状态，再重新加载页面。
- 退出失败时保留当前身份，恢复可操作状态，并在身份区下方显示简短错误和可重试入口。

## 非登录状态

- 检查状态使用与身份行相同高度的紧凑骨架或状态文本，避免侧栏底部跳动。
- 状态检查失败时显示简短错误和“重试”按钮。
- 已退出状态不渲染身份块，由现有登录门禁负责主界面切换。

## 响应式行为

身份区不引入新的断点。它依赖现有侧栏宽度，并在所有宽度下遵循：头像和操作按钮固定，中间文本区域弹性收缩。长姓名和长工号只能截断，不能换行或覆盖相邻元素。

## 测试

组件测试应覆盖：

- 姓名和工号的双行层级。
- 只有工号时不重复渲染辅助行。
- 长姓名、长工号使用可收缩和截断布局。
- 文字头像的字符选择。
- “更多操作”按钮的无障碍名称和菜单开关。
- 退出进行中、退出失败及重试状态。
- 检查中和检查失败状态保持紧凑结构。

## 验收标准

- 姓名、工号和操作按钮不再挤在同一视觉行中。
- 正常侧栏和窄侧栏中均无换行、重叠或横向溢出。
- 姓名始终比工号具有更高视觉优先级。
- 退出登录默认隐藏在“更多操作”菜单中。
- 现有登录状态、生命周期刷新和退出数据流保持不变。
