安装说明

首次安装指引

当前安装包未签名，首次打开时系统可能显示安全提示。

macOS

  1. 打开下载的 DMG，将如影 Code 拖入“应用程序”。
  2. 首次打开如遇安全限制，前往“系统设置”中的“隐私与安全性”。
  3. 确认允许打开如影 Code，然后重新启动应用。

Windows

  1. 运行下载的 EXE 安装程序。
  2. 如出现 Windows SmartScreen 提示，请确认应用来源后选择继续运行。
  3. 按照安装向导完成安装并启动如影 Code。
